### Описание проекта

Веб‑приложение на `Flask` для создания и прохождения общедоступных тестов.  
Функционал:

- **Тесты**: создание, прохождение, редактирование и удаление тестов.
- **Пользователи**: регистрация, авторизация, выход из системы.
- **Роли**:
  - **Администратор**: доступ к управлению пользователями.
  - **Модератор:** доступ к проверке созданных тестов и редактированию любого теста.
  - **Обычный пользователь**: регистрация, вход, создание и прохождение тестов, редактирование своих тестов.
- **REST API**: отдельный `Blueprint` (`/api/...`) для работы с тестами и авторизацией из внешних клиентов.

Данные хранятся в базе **SQLite** (`main.db`) через ORM **SQLAlchemy**.

---

### Используемые технологии

- **Язык**: Python 3.
- **Веб‑фреймворк**: `Flask`
  - роутинг, шаблоны (`Jinja2`), флеш‑сообщения.
- **Аутентификация**: `flask_login`
  - сессии, объект `current_user`, декоратор `user_loader`.
- **ORM и БД**: `flask_sqlalchemy` + `SQLAlchemy`
  - база `sqlite:///main.db` (файл в папке `instance/`).
- **Безопасность паролей**: `werkzeug.security`
  - `generate_password_hash`, `check_password_hash`.
- **HTTP‑клиент для примера API**: `requests` (скрипт `api_example.py`).
- **Шаблоны и статика**:
  - HTML‑шаблоны в `templates/`
  - статика (картинки и т.п.) в `static/`

Все зависимости перечислены в `requirements.txt`

```text

├─ api_example.py       # Пример работы с API через requests

├─ requirements.txt     # Список зависимостей
├─ routes/
│  ├─ auth.py           # /registration, /login, /logout
│  ├─ profile.py        # /profile/*, /notifications/*
│  ├─ tests.py          # /tests, /test/* (просмотр, прохождение, результат)
│  ├─ workshop.py       # /workshop, /create, /createq_*, /addanswer_*, /createnext
│  ├─ edit.py           # /edit-test/*, /edit-question/*, /add-question/*, /delete-*
│  ├─ moderator.py      # /moderator_*, /moderator/*
│  └─ admin.py          # /admin, /admin/*
├─ instance/
│  └─ main.db           # База данных SQLite
├─ templates/           # HTML-шаблоны Jinja2
└─ static/
   ├─ img/              # Загруженные изображения тестов и вопросов
   └─ style/
      └─ style.css
```

**Основные модели** (см. `models.py`):

- **`User`** — пользователь
  - `id`, `username`, `password` (хэш), `email`, `admin` (0/1/2), `current_test_id`
- **`Tests`** — тест
  - `test_id`, `test_id_creator`, `test_name`, `test_description`, `test_status` (0 — разработка, 1 — на проверке, 2 — опубликован), `test_image`
- **`Tests_questions`** — вопрос теста
  - `test_q_id`, `test_q_test_id`, `test_q_text`, `test_q_type` (1/2/3/4 и 11/21/31/41 с изображением), `test_q_status`, `test_q_image`
- **`Tests_answers`** — ответ на вопрос
  - `test_a_id`, `test_a_question_id`, `test_a_text`, `test_a_match` (для типа 4/41), `test_a_is_correct`, `test_a_status`
- **`Test_scores`** — оценка теста пользователем
  - `test_s_user_id`, `test_s_test_id`, `test_s_score` (1–5)
- **`Notifications`** — уведомления
  - `n_user_id`, `n_sender_id`, `n_text`, `n_link`, `n_is_read`, `n_created_at`
- **`TestComments`** — комментарии модераторов к тестам
  - `tc_test_id`, `tc_user_id`, `tc_comment`, `tc_created_at`
- **`UserNotificationSettings`** — настройки email-уведомлений
  - `uns_user_id`, `uns_email_tests`, `uns_email_admin_messages`, `uns_email_account_changes`

### Главные страницы веб‑интерфейса

- **Главная страница (`/`)**
  - описание сайта
- **Список тестов (`/tests`)**
  - полный список существующих тестов
- **Мастерская тестов (`/workshop`)**
  - только для **авторизованного пользователя**
  - создание и редактирование своих тестов
- **Создание теста (`/create`)**
  - только для **авторизованного пользователя**
  - создание нового теста
- **Редактирование теста (`/edit-test/<id>`)**
  - проверка, является ли пользователь создателем теста или модератором
  - редактирование различных частей теста, при редактировании создателем тест должен повторно проверить модератор
- **Профиль пользователя (`/profile`)**
  - только для **авторизованного пользователя**
  - смена имени пользователя, электронной почты, пароля и включение/отключение отправли электронных писем на почту
- **Уведомления (`/notifications`)**
  - только для **авторизованного пользователя**
  - уведомления о изменении созданного пользователем теста, изменении статуса пользователя администратором и отправке сообщения администратором
- **Регистрация (`/registration`)**
  - проверка уникальности логина
  - проверка совпадения пароля и подтверждения
  - отправление сообщения на электронную почту
  - пароли сохраняются в виде хэша
- **Авторизация (`/login`)**
  - вход по логину/электронной почте и паролю
  - проверка хэша пароля
- **Выход (`/logout`)**

### Инструкция для запуска на windows (с виртуальным окружением)

#### 1. Клонирование / копирование проекта

Если проект уже есть на рабочем столе, этот шаг можно пропустить.  
Если используете GitHub:

```powershell
git clone https://github.com/ivan-artemev24/Python-1-Artemev
cd Python-1-Artemev
```

#### 2. Создание и активация виртуального окружения

```powershell

# создать виртуальное окружение (папка venv появится в корне проекта)
python -m venv venv

# активировать окружение
.\venv\Scripts\Activate.ps1
```

При успешной активации в начале строки PowerShell появится префикс `(venv)`.

#### 3. Установка зависимостей

```powershell
pip install --upgrade pip
pip install -r requirements.txt
```

#### 4. Запуск приложения

Запуск основного Flask‑приложения:

```powershell
python __init__.py
```

По умолчанию сервер стартует на:

- `http://127.0.0.1:5000/` — веб‑интерфейс
- `http://127.0.0.1:5000/api/...` — REST API

#### 5. Остановка приложения

В окне PowerShell нажмите `Ctrl + C`.

### Работа с базой данных

- Файл базы: `instance/main.db`.
- При первом запуске (или если файла нет) таблицы создаются автоматически командой `db.create_all()`.
- Модели описаны в `models.py`.
- Для полного сброса данных можно удалить файл `instance/main.db` (при следующем запуске он будет создан заново с пустыми таблицами).
